# Native quota source corrections

The live-usage research is implemented in the existing local usage subsystem. Codex and Antigravity authenticated quota reads pass without model input. Claude's explicitly authorized usage-only terminal route also passes real collection, including a naturally exhausted weekly allowance. The inspected positional route is refused because it can strip cached-data provenance. The screenshot's original group/raw provider response is unavailable; its particular sign-in message has not been attributed to a confirmed incident cause.

## Resolution record

|---|---|

Unrelated success/auth prose cannot override a quota failure, generic mention of quota cannot turn a timeout into exhaustion, and conflicting text remains unknown. ## Actual checks and remaining scope

The exact totals, source/runtime hashes and native dispositions are in [the current machine-readable record](../evidence/live-usage-sources.json). The full suite runs with the pinned existing environment; no dependency/lockfile change is needed. The external manager/naming tests run against temporary fixtures and do not activate a package.

Antigravity returned five numeric quota pools, including an exhausted additional weekly pool, plus a separately measured credit balance. Both local read reports had empty conversation IDs, zero turns and zero invocation token counters; owned providers/descendants/pipes settled. Account values/raw captures stay private. Exact model-to-pool membership remains unknown where the native report omits it; labels/catalog presence alone do not create entitlement or a mapping.

Codex returned native subscription quota through the existing managed build. API-key billing is outside subscription allowance reporting. Optional catalog data is enrichment only. No inference or credit redemption was used for acquisition.

Claude's real usage read and naturally exhausted-account collection pass on the authorized 2.1.309 route. It preserves the implicit default startup config layout and deliberate explicit home overrides. The native panel shows zero API time/cost/invocation tokens, each window is retained and the exact collector UUID has no persisted history. Missing per-turn counters remain unknown. Existing worker/inbox approval is unchanged.

The exact original screenshot incident, native delegation failure-window matrix and fresh all-provider inference are not reaccepted by quota reads. No real spawn is used as a no-turn quota probe. Unknown histories, counters or source precedence are never silently counted as zero or PASS.
